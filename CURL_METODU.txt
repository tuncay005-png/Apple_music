ADDIM 1: Yandex Music açın
═══════════════════════════════════════════════════════════════

Brauzerdə:
https://music.yandex.ru/

Hesabınıza giriş edin (əgər girməmisinizsə)


═══════════════════════════════════════════════════════════════
ADDIM 2: Developer Tools açın
═══════════════════════════════════════════════════════════════

F12 düyməsini basın


═══════════════════════════════════════════════════════════════
ADDIM 3: Network tabına keçin
═══════════════════════════════════════════════════════════════

Yuxarıda "Network" tabına klikləyin


═══════════════════════════════════════════════════════════════
ADDIM 4: Səhifədə bir şey edin
═══════════════════════════════════════════════════════════════

Məsələn:
- Pleylistinizi açın
- Və ya səhifəni yeniləyin (Ctrl+R)
- Və ya bir mahnıya klikləyin

Network tabında REQUEST-LƏR görünəcək


═══════════════════════════════════════════════════════════════
ADDIM 5: Request tapın
═══════════════════════════════════════════════════════════════

Network siyahısında bu adlardan BİRİNİ tapın:

  - account
  - status  
  - feed
  - init
  - playlists

Və ya sadəcə HƏR HANSI request seçin (hansı olursa-olsun)


═══════════════════════════════════════════════════════════════
ADDIM 6: Request-ə SAĞ KLİK
═══════════════════════════════════════════════════════════════

Request-in ADINA sağ klik edin (siçanın sağ düyməsi)

Menyu açılacaq


═══════════════════════════════════════════════════════════════
ADDIM 7: Copy as cURL seçin
═══════════════════════════════════════════════════════════════

Menyuda:

Chrome/Edge:
  Copy → Copy as cURL (bash)

Firefox:
  Copy → Copy as cURL (POSIX)

Klik edin!

cURL əmri clipboard-a kopyalanacaq

═══════════════════════════════════════════════════════════════
